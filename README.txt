THE INVITATIONAL | PRIVATE DEVELOPMENT BUILD

Open index.html in Chrome / Edge for local preview.
The source is split into index.html, styles.css, main.js, and assets/.
No server or domain is required for local testing.

For a local browser test from the folder: python -m http.server 8000
Then visit http://localhost:8000 (only accessible on your computer by default).

This is NOT password-protected. Do not upload the folder to public hosting yet.
If you later want private online staging, use hosting with server-side access controls, not an obscure URL.

The Invitation design and Chronicle records are unchanged from approved V5.
Fonts: Google Fonts require an internet connection; fallback serif/sans-serif are provided.

Approved master logo files are in the original project; deployed assets here are bytewise extracted copies from approved V5.
